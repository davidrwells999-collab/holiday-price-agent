<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry -> repo | Third-party packages and their install scripts enter the build |
| developer machine -> git | Local files (.env, artefacts) could be committed |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-SC | Tampering | npm installs (package.json, pnpm-lock.yaml) | mitigate | Exact pins with save-exact, committed lockfile, `--frozen-lockfile` everywhere, `pnpm view` metadata check, blocking owner checkpoint (Task 2) because no legitimacy audit exists; pnpm 10 blocks install scripts except allow-listed esbuild |
| T-01-01 | Information disclosure | .gitignore | mitigate | `.env`, `.env.*` (except `.env.example`) and `artifacts/` ignored from the first commit |
| T-01-02 | Tampering | src/pricing purity | mitigate | ESLint `no-restricted-imports` blocks IO imports in src/pricing, proven with a probe file |
| T-01-03 | Elevation of privilege | install scripts | accept | Only esbuild may run its postinstall (needed for tsx/drizzle-kit); it is a widely used, verified package |
</threat_model>
