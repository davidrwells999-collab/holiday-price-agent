<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PR author (fork, bot) -> CI runner | Untrusted code runs in CI |
| GitHub secrets -> workflow | ANTHROPIC_API_KEY and POSTHOG_API_KEY |
| third-party actions and images -> CI | Supply chain |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-32 | Information disclosure | secrets on fork/bot PRs | mitigate | Only `pull_request` (never pull_request_target); secrets referenced only in the evals run step, gated on same-repo head and non-bot author; top-level permissions contents: read |
| T-01-33 | Tampering | third-party actions/images | mitigate | Every action pinned to a full SHA, gitleaks and postgres images pinned by tag (gitleaks also by digest); Renovate bumps them via reviewed PRs |
| T-01-34 | Tampering | script injection in workflow | mitigate | Event values (SHAs, author login, repo names) passed via `env:` and quoted, never interpolated into `run:` |
| T-01-35 | Information disclosure | leaked secrets or PII in commits | mitigate | secret-scan job: fixture scan + self-test + gitleaks over full history with --redact; required check |
| T-01-36 | Denial of service | required checks hanging | mitigate | No workflow-level path filters; evals always reports; ci-success uses if: always() |
| T-01-37 | Elevation of privilege | persisted git credentials | mitigate | checkout with persist-credentials: false |
| T-01-38 | Spoofing | review bots approving merges | mitigate | Qodo never required; branch protection lists only our CI jobs |
</threat_model>
